- 나머지 `FAILED` 코드(`TOOL_TIMEOUT_EXHAUSTED`·`TOOL_TEMPORARY_ERROR_EXHAUSTED`·`PERMISSION_DENIED`·`RUN_TIME_LIMIT_EXCEEDED`)는 `GET /analysis-runs/{runId}`의 `failureMessage`(사용자에게 보일 문장, 도구의 화면 이름 포함. 예: "판매량 조회가 시간 초과로 3번 모두 실패했습니다. 잠시 뒤 재분석을 요청하세요.")를 그대로 보여 줍니다. 목록 화면처럼 `failureMessage`가 없는 곳은 상태 라벨만 씁니다.
- 코드별 표시 이름은 따로 두지 않습니다. 표에 없는 코드가 오면 `FAILED`는 `failureMessage`, `ON_HOLD`는 위 고정 문구로 보여 주세요.
